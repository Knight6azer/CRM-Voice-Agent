# Contributing to Riverwood AI CRM Voice Agent

We welcome contributions! Please follow these guidelines to maintain the project's premium standard.

## 🚀 How to Contribute

1.  **Fork the Repository** and create your branch from `main`.
2.  **Ensure Code Quality**:
    - Follow PEP 8 for Python code.
    - Use descriptive variable and function names.
    - Add docstrings to all new functions.
3.  **Design Standards**:
    - Keep the UI vibrant and premium. Use the established color palette (Slate, Blue, Violet).
    - Ensure all components are responsive.
4.  **Testing**:
    - Add tests for any new backend logic in the `tests/` directory.
    - Verify that the FastAPI server and Streamlit app run without errors.
5.  **Submit a PR**:
    - Provide a clear description of the changes.
    - Reference any related issues.

## 🛠 Development Environment
- Python 3.9+
- Recommended: Virtual environment (`venv` or `conda`).
- Linting: `flake8` or `pylint`.

## 📜 Code of Conduct
Be professional, respectful, and collaborative.
